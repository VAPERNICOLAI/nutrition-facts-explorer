ABOUT THE PROJECT

What is NutriFacts?

NutriFacts is a web application designed to make nutritional information simple and accessible.

The application communicates with a free public Nutrition Facts API using JavaScript Fetch and HTTP GET requests.

API Integration

Public Nutrition API

Data Provider: All The Nutrients

Request Method: GET

Response Format: JSON

Authentication: No API Key Required

⚠️ Nutrition Information Notice

Nutrition information displayed by NutriFacts is provided for educational and informational purposes. Values may vary depending on food variety, preparation and serving size.
